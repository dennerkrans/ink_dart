# flutter_ink example

A story on the left, its `StoryDebugView` on the right.

```
flutter run -d chrome   # or -d macos, or a connected phone
```

To play your own story, replace `storyJson` in `lib/main.dart` with a story
compiled by Inky or inklecate. The app runs against the flutter_ink and
ink_dart in this repository (see `pubspec.yaml` and
`pubspec_overrides.yaml`).
